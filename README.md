# TaskFlow

A simple full-stack task management app.

## Features

- Create, edit and delete tasks
- Mark tasks as completed
- Search tasks
- Filter and sort tasks

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- FastAPI
- PostgreSQL

## Getting Started

### Frontend

npm install
npm run dev

### Backend

Activate the virtual environment and run:

uvicorn main:app --reload
